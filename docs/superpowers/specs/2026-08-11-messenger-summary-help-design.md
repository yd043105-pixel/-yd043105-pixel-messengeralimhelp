# 메신저 요약 알리미 지원 안내 페이지 설계

## 목적

메신저 요약 알리미 사용자가 메신저 설치 폴더를 찾고, 폴더 분석 결과 ZIP 파일을 만들어 개발자에게 보내는 과정을 스크린샷 중심으로 따라 할 수 있게 한다. 최종 행동은 생성한 ZIP 파일을 `poo1355@h.jne.go.kr`로 보내는 것이다.

## 사용자와 성공 기준

- 대상: Windows에서 메신저 요약 알리미를 사용하는 비개발자
- 페이지의 단일 목표: 사용자가 설치 폴더 주소를 정확히 입력하고 분석 ZIP 파일을 저장·전송하도록 안내
- 성공 기준:
  - 사용자가 5개 단계의 순서를 한눈에 파악할 수 있다.
  - 각 단계에서 눌러야 할 메뉴와 입력해야 할 값을 스크린샷으로 확인할 수 있다.
  - 실행 파일 경로와 폴더 경로의 차이를 알 수 있다.
  - ZIP 파일에 포함되는 정보와 포함되지 않는 정보를 확인할 수 있다.
  - 마지막에 수신 이메일 주소를 복사하거나 클릭해서 사용할 수 있다.

## 선택한 접근

단계별 지원 가이드 방식을 사용한다. `찾기 → 경로 입력 → 분석 → 동의 → ZIP 저장·전송`을 세로 타임라인으로 표현하고, 각 단계에 실제 스크린샷을 하나 이상 배치한다. 제품 튜토리얼형보다 순서가 명확하고, 인쇄용 매뉴얼형보다 화면에서 탐색하기 쉽다.

## 시각 방향

페이지는 Windows 설정 화면과 파일 경로를 안내하는 “차분한 작업대 + 파일 경로 라벨” 분위기를 사용한다.

- 배경: `#F2F6F6` 밝은 회청색
- 본문: `#142B31` 짙은 청회색
- 단계 진행: `#087F7B` 청록색
- 주의·개인정보: `#D98342` 주황색
- 강조 버튼: `#183B4A` 짙은 남색
- 카드: 흰색과 얇은 회청색 테두리
- 글꼴: `Pretendard`, `Noto Sans KR`, `맑은 고딕`, sans-serif 순서
- 경로·파일명: 고정폭 글꼴로 표시

페이지의 기억점은 각 단계의 `지금 확인할 것` 경로 라벨이다. 실제 경로와 실행 파일명을 한 줄 카드로 보여주어 스크린샷과 설명을 연결한다. 장식은 이 기능을 방해하지 않는 범위에서만 사용한다.

## 정보 구조와 콘텐츠

### 헤더 및 히어로

- 작은 라벨: `업데이트 지원 안내`
- 제목: `메신저 요약 알리미 업데이트를 위한 파일 보내기`
- 설명: `설치 폴더 주소를 찾고 분석 ZIP 파일을 보내주시면 확인 후 바로 업데이트하겠습니다.`
- 보조 문장: `아래 순서대로 천천히 따라 해보세요.`

### 단계 1 — 메신저 바로가기에서 속성 열기

바탕화면의 메신저 바로가기를 마우스 오른쪽 버튼으로 클릭한 뒤 `속성`을 선택한다. 스크린샷 1을 사용한다.

### 단계 2 — 설치 폴더 주소 확인하기

속성 창의 `시작 위치(S)`에 표시된 폴더 주소를 메모한다. `대상(T)`만 사용하는 경우에는 마지막 실행 파일명인 `CoolMessenger.exe`를 제외한 폴더 주소만 사용한다. 스크린샷 2를 사용한다.

### 단계 3 — 요약 알리미의 설정 열기

요약 알리미에서 메뉴의 `설정...`을 열고 메신저 설정 화면으로 이동한다. 스크린샷 3과 4를 사용한다.

### 단계 4 — 메신저와 설치 폴더 입력하기

사용하는 메신저를 선택하고 메신저 실행 파일이 들어 있는 폴더 주소를 입력한 뒤 `이 폴더 분석하기`를 누른다. 스크린샷 5를 사용한다.

### 단계 5 — 동의 후 ZIP 파일 만들기

안내 내용을 확인하고 동의 체크를 한 뒤 `파일 만들기`를 누른다. 저장 대화상자에서 ZIP 파일을 저장한다. 스크린샷 6과 7을 사용한다.

### 개인정보 안내

포함되는 정보:

- 메신저 설치 폴더의 프로그램 파일, DLL, 설정 파일
- 설치 폴더의 파일 목록(이름, 크기)
- 데이터베이스 구조(테이블 이름, 건수)
- 프로그램 설정과 오류 기록

포함되지 않는 정보:

- 쪽지·메시지 본문
- 사람 이름·아이디·부서
- 첨부파일과 첨부파일명
- 원래 날짜·시간 값(익명화된 형식으로 변경)

### 완료 카드

- 제목: `저장한 ZIP 파일을 보내주세요`
- 수신 주소: `poo1355@h.jne.go.kr`
- 행동: 이메일 주소 클릭 또는 복사
- 안내: `파일을 보내주시면 메신저 지원을 추가하고 바로 업데이트하겠습니다.`

### 문제 해결

설치 폴더를 찾을 수 없을 때는 속성 창에서 `파일 위치 열기`를 사용하거나, 메신저 바로가기의 `시작 위치(S)`를 다시 확인하도록 안내한다. 폴더를 선택할 때 실행 파일 자체가 아니라 실행 파일이 들어 있는 폴더를 입력해야 한다는 문장을 별도로 강조한다.

## 구현 구조

- `index.html`: 의미 있는 HTML 구조, 단계별 콘텐츠, 접근성 레이블, 이메일 링크
- `styles.css`: 색상 토큰, 타임라인 레이아웃, 카드·경로 라벨·반응형 스타일, 키보드 포커스, reduced motion 대응
- `script.js`: 이미지 확대 모달과 이메일 주소 복사 기능만 담당한다. 복사 실패 시 주소를 직접 선택할 수 있는 기본 동작을 유지한다.
- `assets/step-01-context.png`부터 `assets/step-07-save.png`: 제공받은 스크린샷의 작업 폴더 사본

외부 CDN, 웹폰트, 빌드 도구, 서버, 추적 코드는 사용하지 않는다. `index.html`을 파일 탐색기에서 직접 열어도 동작해야 한다.

## 상호작용 및 예외 처리

- 스크린샷 클릭 시 같은 페이지 안에서 확대 모달을 열고, `Esc`·닫기 버튼·배경 클릭으로 닫는다.
- 모달에는 이미지 설명을 `aria-label`로 제공하고, 닫은 뒤 원래 썸네일로 포커스를 돌려보낸다.
- 이메일 주소 복사 버튼은 Clipboard API가 가능할 때 복사하고, 불가능하면 주소를 선택해 복사하도록 안내한다.
- JavaScript가 동작하지 않아도 모든 단계 설명, 이미지, `mailto:` 링크가 보이도록 설계한다.
- 화면 폭이 좁아지면 타임라인의 왼쪽 레일을 접고, 단계 카드와 이미지를 단일 열로 배치한다.
- `prefers-reduced-motion: reduce`가 켜져 있으면 등장 애니메이션을 제거한다.

## 검증 계획

- `index.html`을 로컬에서 직접 열어 모든 이미지가 표시되는지 확인한다.
- 각 스크린샷 썸네일을 클릭해 확대·닫기가 동작하는지 확인한다.
- 복사 버튼의 성공·실패 상태를 확인하고 `mailto:` 링크가 올바른 주소를 가리키는지 확인한다.
- 375px, 768px, 1280px 폭에서 레이아웃이 깨지지 않는지 확인한다.
- 키보드로 단계 링크, 이미지 확대, 모달 닫기, 이메일 링크에 접근할 수 있는지 확인한다.
- 개인정보 안내가 스크린샷의 표시 내용과 일치하는지 최종 확인한다.
