FOLLOW THE PATH / 01—05

설치 폴더를 찾고
분석 파일을 만들어주세요

각 단계의 화면을 클릭하면 크게 볼 수 있습니다. 버튼 이름은 화면에 보이는 그대로 적었습니다.

01

메신저 바로가기

바탕화면에서 속성을 열어주세요

메신저 프로그램 바로가기를 마우스 오른쪽 버튼으로 클릭한 뒤, 메뉴 아래쪽의 속성을 선택합니다.

↗ 우클릭 → 속성
02

속성 / 바로 가기

실행 파일이 있는
폴더 주소를 메모하세요

시작 위치(S)에 표시된 주소를 메모합니다. 이 항목이 보이지 않으면 대상(T)에서 마지막 실행 파일명만 뺀 주소를 사용하면 됩니다.

지금 확인할 것 C:\Program Files (x86)\CoolMessenger Gentoo

※ CoolMessenger.exe까지 입력하지 않습니다.

03

메신저 요약 알리미

프로그램에서
설정을 열어주세요

메신저 요약 알리미를 실행합니다. 오른쪽 위의 메뉴를 열고 설정...을 선택한 다음, 설정 창에서 메신저 다시 설정...을 누릅니다.

☷ 메뉴 → 설정...
04

처음 설정

메신저를 고르고
설치 폴더를 입력하세요

사용 중인 메신저를 선택하고, 2단계에서 메모한 폴더 주소를 메신저 설치 폴더 칸에 입력합니다. 입력 후 이 폴더 분석하기를 누릅니다.

입력할 폴더 C:\Program Files (x86)\CoolMessenger Gentoo

실행 파일이 아니라 실행 파일이 들어 있는 폴더를 입력합니다.

05

문제 보고 파일

내용을 확인하고
ZIP 파일을 만들어주세요

분석되는 내용을 읽고 동의 체크를 합니다. 그 다음 파일 만들기를 누르고, 저장 창에서 ZIP 파일을 저장합니다.

내용 확인→동의 체크→파일 만들기

  • 메신저 설치 폴더의 프로그램 파일·DLL·설정 파일
